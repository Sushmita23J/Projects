☕ Coffee Shop Sales Analysis 📊
This project presents a sales analysis of a coffee shop using Microsoft Excel. The goal is to derive meaningful insights from raw sales data to help understand business performance, customer preferences, and sales trends.

📁 Project Overview
Project Type: Data Analysis

Tool Used: Microsoft Excel

Dataset: Coffee shop sales data (includes date, product, sales, location, etc.)

Techniques Applied: Data cleaning, Pivot Tables, Charts, and Dashboard creation

🔍 Objectives
Analyze sales performance by product, category, and location

Identify top-selling items and peak sales periods

Visualize sales trends using interactive dashboards

Support data-driven decision making for marketing and inventory management

🛠 Key Features
Cleaned and organized raw sales data for accurate analysis

Used Pivot Tables to summarize and segment data

Created various charts (Bar, Line, Pie) for visual representation

Built an interactive dashboard for at-a-glance performance insights

📈 Insights Derived
Peak hours and top-performing days identified

Best-selling drinks and products highlighted

Seasonal and category-wise sales patterns observed
